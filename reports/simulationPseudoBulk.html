Simulation strategy

Experimental Data

To generate our data, we will use the dataset obtained from Brunner et al. 2022. (Label-Free). We will isolate only one condition (Untreated). For this condition we compute for each protein; his mean log-intensity and his standard deviation

Intensities modelling

Let \(X_{ij}\) denote the log-intensity of protein \(i\) in cell \(j\).

We model the log-intensity as:

\[ X_{ij} = \mu_i + \epsilon_{ij} + A^{\text{patient}}_i \cdot \delta^{\text{patient}}_{i, p_j} + A^{\text{treatment}}_i \cdot \delta^{\text{treatment}}_i \cdot \mathbb{I}_{t_j = 1} \]

Where:

  • \(\mu_i\): baseline log-intensity of protein \(i\) obtained from experimental data
  • \(\epsilon_{ij} \sim \mathcal{N}(0, \sigma_i^2)\): residual noise obtained from experimental data
  • \(A^{\text{patient}}_i\): indicator if protein \(i\) is affected by patient-specific shifts
  • \(A^{\text{treatment}}_i\): indicator if protein \(i\) is affected by treatment
  • \(p_j \in \{1, \ldots, P\}\): patient identity of cell \(j\)
  • \(t_j \in \{0,1\}\): treatment status of cell \(j\) (1 = treated)
  • \(\delta^{\text{patient}}_{i, p} \sim \mathcal{N}(0, \sigma_{\text{patient}}^2)\): patient-specific shift for protein \(i\) and patient \(p\)
  • \(\delta^{\text{treatment}}_i \sim \mathcal{N}(0, \sigma_{\text{treatment}}^2)\): treatment effect for protein \(i\)
  • \(\mathbb{I}_{t_j = 1}\): indicator function equals 1 if cell \(j\) is treated, 0 otherwise

Missing Data Modelling

Each \(X_{ij}\) is observed with probability \(1 - \pi_i\), where:

\[ M_{ij} \sim \text{Bernoulli}(\pi_i) \]

If \(M_{ij} = 1\), then \(X_{ij} = \text{NA}\).

Where \(\pi_i\) is the experimentally observed missing rate of protein \(i\) .

  for (j in 1:nCellTypePerPatient) {
    thisCellType <- paste0("Type", j)

      shiftVec[cellTypeShiftProteins]
  }

treatment_vector <- character(ncol(simSCE))
names(treatment_vector) <- colnames(simSCE)

# Get colData
cd <- colData(simSCE)

# Loop over each patient-subtype group
for (p in unique(cd$patient)) {
    # Find cell indices in this group
    group_cells <- which(cd$patient == p)
    
    # Shuffle and assign 50% treated, 50% control
    n_group <- length(group_cells)
    n_treat <- floor(n_group / 2)
    
    treated_cells <- sample(group_cells, size = n_treat)
    control_cells <- setdiff(group_cells, treated_cells)
    
    treatment_vector[treated_cells] <- "treated"
    treatment_vector[control_cells] <- "control"
  }

# Assign to colData

# Select affected proteins

Apply PseudoBulk + msqrob2

aggregate_se <- function(se, group_by_cols, fun = mean) {
    if (!all(group_by_cols %in% colnames(colData(se)))) {
        stop("Some specified group_by_cols do not exist in colData.")
    }
    colData(se)$Group <- apply(colData(se)[, group_by_cols, drop = FALSE], 1, paste, collapse = "_")
    group_factor <- factor(colData(se)$Group)
    assay_matrix <- assay(se)

    # Aggregate assay matrix by group_factor levels order
    grouped_indices <- split(seq_along(group_factor), group_factor)
    levels_group <- levels(group_factor)  # factor levels in order
    aggregated_assay <- do.call(cbind, lapply(levels_group,
                                              function(g) {
                                                  idx <- grouped_indices[[g]]
                                                  apply(assay_matrix[, idx, drop = FALSE], 1, fun, na.rm = TRUE)
                                              }))
    new_colData <- colData(se) %>%
        as.data.frame() %>%
        group_by(Group) %>%
        summarise(across(all_of(group_by_cols), dplyr::first), .groups = "drop") %>%
        as.data.frame()
    # Reorder new_colData rows to match factor levels
    new_colData <- new_colData[match(levels_group, new_colData$Group), ]
    rownames(new_colData) <- new_colData$Group
    new_se <- SummarizedExperiment(assays = list(aggregated_assay),
                                   colData = new_colData,
                                   rowData = rowData(se))
    return(new_se)
}
